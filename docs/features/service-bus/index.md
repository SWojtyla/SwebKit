# Service Bus

## Purpose

Expand Service Bus tooling from basic inspection to high-value operational workflows for DLQ remediation, message composition, reusable templates, and repeatable scenarios.

## Scope

- DLQ batch operations and safety confirmations
- Message composer and send flows
- Message templates and scenario execution
- Favorites, live counts, auto-refresh, and filter persistence
- Export and advanced filtering support

## Logical Outcome

A practical Service Bus operations workspace that supports fast and safe debugging in non-prod and guarded mutation in prod.
