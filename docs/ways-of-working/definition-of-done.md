# Definition of Done

Minimum criteria before marking a feature as done:

- Implementation aligns with `docs/features/active/<feature>/index.md`
- Tests covering new behavior added or updated
- `status.md` shows validation status and remaining work (none)
- `decisions.md` contains any architecture or trade-off notes
- Docs cleaned (no temporary `notes*.md`) and ready to archive

Use this checklist when closing work and moving the feature to `docs/features/archive/`.
