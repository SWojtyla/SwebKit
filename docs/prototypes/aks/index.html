AKS — top-bar prototypes

Three directions for decluttering the 18-resource nav (8 direct tabs + 6 hidden behind Network ▾ + 4 trailing). Click a card to open the interactive mock. Nothing is wired — evaluate the shape, not the pixels. Mock data only.

A — Grouped menus category dropdowns

The flat tab strip collapses into 4 labelled menus — Workloads / Configuration / Network / Operations — each opening a dropdown with item counts and one-line descriptions. The active view shows as a crumb (Workloads › Pods). Same horizontal-bar mental model, no second-class submenu.

least re-learningequal footing for all 18counts up front

B — Navigator rail Lens-style sidebar

Resource navigation moves into a collapsible left rail: grouped sections, live count badges, a filter box at the top. All 18 resources visible at once, always. The top bar slims down to scope (context / namespace) + refresh. Costs ~210px of horizontal space (collapsible to icons).

best discoverability1 click to anythingsteals list width

C — Breadcrumb + switcher progressive disclosure

One line of chrome: cluster › namespace › resource, where each segment is a picker. The resource segment opens a Ctrl+K-style searchable switcher (recent items, grouped list, arrow-key navigation). A pinned-favourites strip keeps power users one click from their usual spots.
