# Privacy Policy Summary for SwebKit

**Effective Date:** March 16, 2026

## Overview

SwebKit is a developer toolkit that helps you inspect and debug your Azure Service Bus, Application Insights, and AKS (Kubernetes) resources directly from your desktop.

## Data Collection

We DO NOT collect, store, or transmit any personal data to our servers.

## Local Storage

The app stores the following data ONLY on your local device:

- Azure Service Bus connection strings (encrypted)
- Azure Monitor / Application Insights connection strings or API keys (encrypted)
- Kubernetes configuration (kubeconfig path and connection details)
- Project and environment definitions
- Your application preferences

## Data Security

- All credentials are encrypted using Microsoft's Data Protection API
- All data remains on your device
- No data is sent to any third-party servers

## Third-Party Services

The app connects ONLY to your own cloud resources (Azure Service Bus, Azure Monitor, AKS clusters). We do not use analytics, tracking, or advertising services.

## Your Rights

You can delete all app data at any time through:

- The app's interface (delete individual connections/projects)
- Deleting local application data files

## Contact

GitHub: https://github.com/SWojtyla/SwebKit

## Open Source

This app is open source. Review our code and privacy practices at the GitHub repository above.

**Privacy Statement for Microsoft Store:**
